## Development Rules

Before implementing a major feature:

1. Inspect the existing project.
2. Understand the current architecture.
3. Plan the implementation.
4. Implement only what is necessary.
5. Test the implementation.
6. Check responsive behavior.
7. Check accessibility.
8. Check animation performance.
9. Check production build.

Do not rewrite unrelated code.

Do not create duplicate components.

Do not install dependencies without a clear reason.

Prefer reusable components.

Keep components maintainable.

Do not over-engineer simple sections.

---

## Performance

The site may contain advanced animation and 3D, but performance is critical.

Prioritize:

- GPU-friendly transforms
- lazy loading
- dynamic imports for heavy 3D components
- reduced unnecessary React renders
- optimized images
- optimized fonts
- responsive 3D quality
- reduced-motion support
- avoiding excessive DOM nodes
- avoiding unnecessary WebGL scenes

The experience should feel fast even though it is visually sophisticated.

---
